# SQLite 索引升级

应用使用 `utils/question_index.sqlite3` 作为本机题库索引。现有题目、目录、图片和 `.tex` 文件保持原位，不需要改格式，也不需要安装数据库服务器。

## 首次迁移

首次读取索引时，程序在一个 SQLite 事务中导入原 `utils/题库索引表.csv` 的全部字段，包括题目 ID、标签、难度、来源、引用次数与首次录入时间，并一次性建立中文检索索引。迁移核对完成后，可按需清理旧 CSV；本机已按用户要求移除旧索引及其 CSV 备份。旧 `local_stats.sqlite3` 中的活动记录一并复制，旧文件保留；迁移不会把历史题目计作今日新增。

没有 CSV 时，从 `chapters/` 中的题目建立索引。重复 ID、重复路径或关键字段缺失会中止迁移，事务回滚，不修改 CSV 或题目文件。修复旧索引的问题后重新打开即可重试。

## 日常使用

- 按录入时间浏览由 SQLite 排序和分页，只取当前页的元数据，随后读取该页 `.tex`。
- 精确搜索在数据库内完成字段筛选，支持原有的文字、公式、标签、难度等组合条件。子串筛选使用字面匹配，`%`、`_` 不作为通配符。
- 模糊搜索使用 FTS5 字符索引筛选候选，保存时预先生成规范化文本，再沿用原来的中文分词、关联词、近似词与相关度算法。候选不作 top-k 截断，保留完整召回与分页排序。
- 保存、重命名、删除单题时，同一事务更新对应的索引、全文检索和活动记录，不再重写整个 CSV。题目 ID 由数据库事务分配，避免并发操作取得相同 ID。
- 首页读取轻量元数据及已有活动汇总，不再对全库题干和解析逐条计算指纹、回写统计快照。
- 缓存使用数据库提交版本失效，包含尚在 WAL 文件中的提交，保存后无需重建索引即可检索新内容。

语义向量索引仍是独立、可选的 `semantic_index.sqlite3`。此次升级不改变 embedding API 配置，也不会调用网络生成向量。

## 外部文件变动与同步

使用外部编辑器修改题目，或在资源管理器中复制、移动、删除文件后，请运行“维护工具 → 一键重建/同步题库索引”，或：

```powershell
python utils/init_sqlite_index.py
```

重建以 `.tex` 内容为准，优先保留最新 SQLite 中的 ID、首次录入时间及手工标签，重建仅更新 SQLite，不再自动生成 CSV。旧 `read_csv_index` / `write_csv_index` 接口保留供现有工具使用，实际读写 SQLite。

手动删除的题目可能暂时仍计入搜索结果；界面只检查当前页文件并提示重建，避免每次查询都检查数万个文件。

## 备份与验证

备份时先关闭应用，再复制 `chapters/`、`.env`、导出文件和 `utils/question_index.sqlite3`；若仍有同名 `-wal` 文件，请一并保留，或使用 SQLite 的在线备份 API。旧统计库可继续保留，CSV 不再是运行或备份所必需的文件。SQLite 索引及 WAL/SHM 不进入 Git 或空题库发行包。

本次升级的功能验证和 5 万题基准测试已完成，新增测试脚本、基准脚本及临时数据已按用户要求清理，项目原有测试保留。以下计时只代表本机后端，不包含浏览器、题目预览和 TeX 编译。

2026-11-05 本机测试：由 70 条快照扩展为 50,000 条，CSV 约 155 MiB，含规范化文本和全文检索的 SQLite 约 832 MiB。日常操作为 3 次测量的中位数：

| 操作 | 后端耗时 |
|---|---:|
| 浏览首页（10 题） | 23 ms |
| 浏览末页（10 题） | 184 ms |
| 首页统计 | 432 ms |
| 精确全文搜索 | 1.0 s |
| 模糊搜索“洛伦兹力” | 1.7 s |
| 模糊搜索“磁场 粒子 圆周运动” | 1.8 s |
| 单题索引保存 | 20 ms |

该规模的首次迁移及建索引用时约 161 秒，只执行一次；不能将其与日常打开或单题保存时间混淆。真实本机旧索引 70 条已完成迁移，全部 25 个字段与旧 CSV 一致，正式题目源文件均已保留，相关图随同期外部图片编辑同步更新；确认迁移后已清理旧 CSV 及其索引备份。

已有旧版本全文检索表会自动升级到列级检索配置，并在事务内重建 FTS；题目和元数据不受影响。该升级同时修复旧表导致模糊搜索与保存查重报错的问题。

清理验收后，已删除临时验收题、本次新增测试与基准脚本、临时产物及旧题库 CSV 备份，并移除旧 CSV 中一条指向不存在 `test_time.tex` 的历史测试索引；当前为 69 道有实际源文件的有效题目。项目原有测试代码保留。
