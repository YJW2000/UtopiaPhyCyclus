# 便携版体积优化

在已通过验证的完整 Windows ZIP 上运行：

```powershell
python tools/release.py slim
```

输出位于 `dist/<版本>-slim/`。该命令不会改动完整发行 ZIP 或个人数据目录，也不会重新冻结、升级或替换应用依赖。

主包只移出 TeX Live 的 `texlive.tlpdb` 明确列为 `docfiles`、位于 `texmf-dist/doc/` 下的普通 PDF 手册。名称包含许可或版权标记的文件保留在主包中，宏包源码、非 PDF 文档、字体、引擎、Python、Node 和原始 Whisper small 模型均保留。

可选的 `tex-reference.zip` 保留手册原始内容和路径。需要查阅手册时，将其解压到主包的上级目录并合并同名应用文件夹。完整原发行包及完整的第三方文档仍在对应 GitHub Release 提供；版权声明、各包源码及源代码获取信息继续随主包提供。TeX Live 逐包许可仍适用；LPPL 条款参见 https://www.latex-project.org/lppl/lppl-1-3c/ 。

构建程序核对原包的验证报告和 SHA-256，检查归档路径，并验证所有保留文件的内容与原包完全一致。主包中的 `runtime-manifest.json` 更新为实际随包文件列表；移出的每个手册记录在 `slimming-report.json` 和手册附件清单中。两份 ZIP 合并后，除更新后的运行库清单外，全部原文件均可恢复为原始字节。

构建后的 CRC 与内容校验不能代替运行验收。精简 ZIP 应重新进行依赖检查、SQLite/FTS 搜索保存、模板 PDF 编译、真实离线语音以及英文和中文目录下的工作台会话验证。实际执行结果另存验证报告，不沿用完整包的执行结论。

不默认缩小或量化语音模型：这会改变识别结果。也不按一次样例运行中用到的文件裁掉宏包或字体，以免遗漏其他已有模板所需资源。
