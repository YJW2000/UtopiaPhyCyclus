# UtopiaPhyCyclus 1.2.0

本发行版为空题库版本。没有预置内部题目、配图、答案、CSV 索引、数据库、API 密钥、历史导出或旧 Git 历史。

## Windows 便携版

下载 `UtopiaPhyCyclus-1.2.0-windows-x64.zip`，完整解压到有写入权限的文件夹，然后双击 `UtopiaPhyCyclus.exe`。不要只复制 exe，也不要直接在压缩包里运行。浏览器自动打开本地工作台；关闭启动控制台会结束服务。

文件名以 `-windows-x64-slim.zip` 结尾的是精简便携包：应用及运行资源与完整版一致，仅将 TeX 的普通 PDF 手册分为可选的 `-tex-reference.zip`。不需要手册即可运行全部已有功能；需要查阅时，将手册附件解压到主包的上级目录并合并同名文件夹。处理规则与验证方式见 [便携版体积优化](便携版体积优化.md)。

该完整 Windows 版内置 Python、项目所需的 TeX Live 宏包及中文字体、Node、CPU Whisper 运行库和 small 多语言模型，无需另外安装这些环境。使用内置的题库、PDF、插图预览和本地语音功能，只需完整解压；AI 功能再填写用户自己的 API 地址、模型和 Key。麦克风首次使用时需要允许浏览器访问。首次启动可能准备兼容中文路径的 TeX 缓存。

支持范围、x32 原因与测试边界见 [Windows兼容性与测试.md](Windows兼容性与测试.md)。这是空题库发行，用户需自行导入有权使用的题目。

完整包包含大型离线模型与 TeX 资源，建议使用 8 GB 或更多内存，并为下载、解压和首次运行缓存预留至少 4 GB 磁盘空间。

在工作台设置中填写个人 AI 配置，或把 `env.example` 复制为 `.env`。题目存放在解压目录的 `chapters/`，首次录入时创建分类与本地索引。升级前备份 `chapters/`、个人 `.env` 和导出文件；新版本解压至新目录后再迁移个人数据。

## 从旧版本升级

备份原目录后，将新版解压到新目录，再迁移 `chapters/`、个人 `.env` 和需要保留的 `utils/question_index.sqlite3`。若只有旧 CSV，可一并迁移以便首次启动自动导入；迁移核对后可移除 CSV。不要用空题库覆盖个人题目目录。

## Python 安装包

支持 Python 3.10–3.12。建议在独立虚拟环境安装：

```powershell
python -m pip install .\utopia_phycyclus-1.2.0-py3-none-any.whl
utopia-phycyclus --data-dir D:\UtopiaPhyCyclusData
```

启动器会把只读软件资源复制到指定的独立工作目录，个人题目和配置保存在那里。省略 `--data-dir` 时使用用户主目录下的 `UtopiaPhyCyclus`。相同版本重复启动保留工作目录；升级软件时请使用新的工作目录并迁移个人数据。

wheel 和源码压缩包不捆绑大型运行库。需要全部内置环境的普通 Windows 用户应下载完整 Windows ZIP。

## 源码启动

源码压缩包解压后，双击 `启动乌托邦高中物理题库助手.bat`，首次运行联网安装 Python 依赖。也可以 `python -m streamlit run utopia_phycyclus_app.py`。

## 重新构建

在 Windows x64、Python 3.12 环境中运行：

```powershell
python -m pip install -r requirements-lock.txt -r requirements-build.txt
python tools/release.py prepare
python tools/release.py build
python tools/release.py audit
```

完整包验证报告就绪后，可运行 `python tools/release.py slim`，在独立的 `dist/<版本>-slim/` 中生成精简包与可选手册附件；不覆盖原版。生成后须重新验收精简 ZIP，并单独提供其验证报告与校验值。

`prepare` 使用显式白名单生成 `.release-work/source/`，不会复制本机 Git 历史。`build` 生成源码 ZIP、wheel、sdist、Windows x64 便携 ZIP、文件清单与 SHA-256。`audit` 检查实际文件路径、密钥特征及本机内部题库文件的 SHA-256，命中即失败。可发布仓库为 `.release-work/source/`，禁止从原工作目录直接 `git add .` 后推送。

构建前还需准备 `.release-work/runtime-assets/windows-x64/`：可以从同版本完整 ZIP 复制 `runtimes/` 与 `runtime-manifest.json`，保留原始哈希。也可以使用 `tools/bundle_runtimes.py --help`，从官方 TeX Live 安装、公开 MIT whisper.node npm 包、官方 Node 及经校验的 Whisper small 模型重新生成。参数 `--speech-plugin` 只读取该目录下的两个公开 npm 包，不分发私有 DSH 插件本体。宏包源码与文档随 TeX 子集保留，来源、许可与每个文件的哈希随运行库提供。

完整包构建结果位于 `dist/1.2.0/`。运行 `UtopiaPhyCyclus.exe --self-test` 进行无需 API 的 PDF 和离线语音验收。

源码、本项目构建脚本和许可随发行版提供。PyMuPDF/MuPDF 源码以及其他第三方组件源码入口见 THIRD_PARTY_NOTICES.md 与发行版的 dependency-sources.json。
