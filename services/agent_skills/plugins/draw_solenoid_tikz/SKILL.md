# 螺线管 TikZ 原图绘制

## 目标

按原图的可见线表达绘制绕组，使绕向、引线接头和电源极性能够直接辨认。不要把教材的示意绕组擅自改成完整数学螺旋。

## 工作流程

1. **先核对原图。** 扫描件先提取原生高清图，再裁出绕组、两侧接头和电源；不要仅凭低分辨率缩略图猜绕向。
2. **识别绘图约定。** 判断原图是“只画可见线”还是“同时画背面线”。原图省略背面时，不添加虚线、背面半环或连续参数螺旋。
3. **先定电路，再定绕向。** 认定长极板为正极、短极板为负极，从正极沿外电路追踪到绕组，确认电流从哪一端进入、从哪一端离开。
4. **选择对应模板。** 水平铁芯使用“顶弧—正面斜线—底弧”模式；竖直螺线管使用“正面横弧—左右侧弧”模式。
5. **共用接头坐标。** 让最后一匝、外接引线和电源连接使用完全相同的坐标，不用目测补线。
6. **编译并渲染切片。** 对照原图验收后再交付。

## 原图可见线的硬规则

- 原图没有背面线时，禁止自行补背面虚线。
- 不要为了让路径在数学上连续而增加原图没有的环、斜线或连接线。
- 正面可见段的方向必须与原图一致；本技能原型中，水平铁芯为“左上→右下”，竖直螺线管正面横弧从右侧端点追到左侧端点。
- 保留原图的省略方式；可见弧段之间不要求在纸面上全部首尾相接。
- 标签不得压住绕组、接头或极板；必要时使用白底标签并移离线条。

## 两类原型的计数与方向

以下计数对应本技能的教材原型；其他题目仍以各自原图为准。

| 原型 | 可见组成 | 末端处理 |
|---|---|---|
| 水平铁芯，N 匝 | N 个顶部小弧、N 根正面斜线、N−1 个底部小弧 | 最后一根正面斜线直接接右侧引线，不再额外画底弧 |
| 竖直螺线管，N 匝 | N 条正面横弧、N 个左侧上回弧、N−1 个右侧下连弧 | 最下方横弧的右端按原图直接接外电路 |

### 水平铁芯

1. 先画铁芯矩形，再画可见绕线。
2. 第 i 匝顶弧圆心横坐标记为 `c_i`，顶弧左右端为 `c_i-r`、`c_i+r`。
3. 正面斜线从顶弧右端 `(c_i+r, coreTop)` 开始，到 `(c_i+r+s, coreBottom)` 结束，保持左上到右下。
4. 前 N−1 匝从正面斜线下端继续画底部 U 形小弧；最后一匝的下端直接作为右侧引线接头。
5. 左侧引线按原图从铁芯下沿引出；不要因为看不到背面连接而自行补线。

### 竖直螺线管

1. 画圆柱侧壁、顶部椭圆和底部可见弧，再画绕组可见线。
2. 每条正面横弧从左端 `(0,y)` 画到右端 `(1,y-0.05)`，中部略向下弯。
3. 左侧回弧向外鼓出并向上返回；右侧连弧向外鼓出并向下连接。
4. 只在前 N−1 条横弧右侧画下连弧；最下方横弧右端直接接外电路。
5. 若原图规定“下方直接绕到电源正极”，让最下方横弧右端与通往长极板的导线共用坐标，并检查没有把电池极板画反。

## 电源与接头检查

- 长极板 = 正极；短极板 = 负极。
- 先核对原图极板长短，再画连接，不要按习惯随意放置正极。
- 最下方横弧右端、水平外引线起点必须逐坐标一致。
- 水平铁芯最后一根正面斜线下端、右侧竖直引线上端必须逐坐标一致。
- 滑动变阻器按原图核对滑片、电阻体和外接端子的连接关系。

## 验收闭环

1. 用 XeLaTeX 至少编译两遍，检查错误和排版警告。
2. 将每幅绕组以约 5 倍缩放渲染成局部图片。
3. 对照原图逐项检查：匝数、正面方向、顶底弧或左右侧弧数量、最末匝处理、电源极性、外接端子。
4. 确认没有擅自出现背面虚线，且文字不被线条穿透。
5. 实际查看渲染图后再报告完成；只编译成功不能证明绕向和接头正确。
